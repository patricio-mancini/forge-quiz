# SSD Framework (ForgeQuiz)

This folder defines the **Spec-Driven Development (SSD)** framework for ForgeQuiz.

## What to read (minimal context)

- `SSD_SDLC.md`: the lifecycle gates (spec → plan → code → verify → docs)
- `runbooks/`: procedural guides to produce `SPEC.md` / `PLAN.md` / execution outputs deterministically
- `CONTRACTS.md`: what “contracts” are, where they live, and how to version them
- `ADR_PROCESS.md`: when decisions require ADRs
- `NAMING.md`: naming conventions for specs and ADRs
- `templates/`: copy/paste templates for new work

## Policy authority (avoid duplication)

- Repo governance + principles live in `CONSTITUTION.md`
- Operational lifecycle gates live in `SSD_SDLC.md`
